# Luma Music – Responsive Music Streaming Web App

Luma is a responsive music streaming web interface built with HTML5, CSS3,
and vanilla JavaScript. It has a three-panel dashboard layout (navigation
sidebar, content area, and now-playing panel) and a working audio player
built on the HTML5 Audio API.

## Features
- Audio playback with play/pause, seek bar, volume control, and mute
- Next/previous track navigation, shuffle, and auto-play of the next track
- Now-playing panel with dynamic track title and artist updates
- Like/favorite toggle and toast notifications for user feedback
- Real-time search that filters albums by title or artist
- Clearable "Up next" queue
- Responsive design for desktop, tablet, and mobile (CSS Grid, Flexbox, media queries)
- Accessibility support with ARIA labels and live regions

## Tech Stack
HTML5 · CSS3 (Grid, Flexbox, Custom Properties) · JavaScript (ES6) · HTML5 Audio API · Google Fonts

## Getting Started
1. Clone the repository
2. Open `index.html` in your browser
